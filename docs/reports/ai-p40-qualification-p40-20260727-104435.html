왜 달라졌나

512 context가 가득 찬 sliding 전환 뒤 base decoder는 오래된 token을 버리고 전체 window hidden state를 다시 계산합니다. cache 후보는 남은 token의 과거 hidden state를 유지하므로 수치적으로 동일하지 않습니다.

다음 비교는 exact-cache · periodic re-prefill · 5/15분 context 정책입니다.

각 후보를 동일 origin에서 base와 다시 비교하고 prediction digest 또는 승인된 tolerance gate를 통과시킨 뒤에만 5주 성과 검증으로 확장합니다. 현재 구현은 실험 플래그로 유지하고 production 기본값은 비활성으로 둡니다.
